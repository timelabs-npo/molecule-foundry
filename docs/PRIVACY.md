# Molecule Foundry game privacy

Version 0.1.0, 21 November 2026.

The iPhone game is designed to run offline. Game progress is stored locally on the device. This build does not include advertising, analytics SDKs, account registration, location access, microphone access, camera access, or collection of personal health data.

Clinical participants, results, symptoms, and outcomes displayed in the game are fictional simulations. No human trial data is entered or collected by the game.

Opening a source-reference link takes you to the named external website, whose privacy policy applies. Apple may separately provide TestFlight diagnostics and feedback under its own services and settings.

The separate developer control plane requires sign-in and stores development tasks, configuration drafts, the signed-in developer identity, and an audit journal for the authorized project team. It is not part of the offline game and does not receive game saves.

For project questions, use https://github.com/timelabs-npo/molecule-foundry/issues. Do not post credentials or private health information there.
